# Reporting Guidelines

_Target venue: **IEEE SaTML**. This is a style guide, not a manual._

## Format

- **IEEE two-column.** The current draft is in USENIX format and must be converted; `docs/iri/IRI_paper.tex`
  is already IEEE and its template can be reused.
- Terminology follows the draft: **forcing floor**, `τ̂rec`, **EMR**, **capacity**, **probe**,
  `α_k`, `k⋆`, `β`. Keep the English terms verbatim in discussion; do not invent translations.

## Uncertainty — three hard rules

**① Never report a bare mean.** Effect size + interval + n, all three.

```
✗  52.0
✓  52.0% [−26, 26], n=25
```

**② `EMR(D)` never appears alone.** It is always paired with `α_k`, the forcing floor. This is the
draft's own rule from §3.6: `(rate, floor)` is the minimum publishable pair. An extraction rate
without a floor is a statement about the attack, not about the model.

**③ A complete report carries five quantities**: `EMR(D)` · `α_k` · `τ̂rec[CI]` · `AUC[CI]` · `ε̂`.

> Current gap: Table 4 omits `ε̂` (**which has no implementation in the code**), and `TPR@α` is
> already computed by `table1_main` but never reaches the paper. The first needs about ten lines of
> code; the second is pure transcription.

## Confidence intervals — one convention

There is an inconsistency to resolve: §6.3 says "person-clustered bootstrap", Table 4's caption says
"Newcombe (Wilson-score)", and `make_tables.py` **implements only bootstrap**.

**Convention**:

- **Default to person-clustered bootstrap** (`_cluster_emr_ci` / `_cluster_diff_ci`, N=10000,
  resampling unit is `person_id`)
- **Switch to Newcombe when a zero-count arm degenerates the bootstrap** (e.g. Pythia-2.8B's
  EMR(C) = 0/12)
- **State in the table note which rows used Newcombe.** Never mix two methods in one table without
  the reader being able to tell.

## Labelling exploratory results

**Mark them in the table itself**, not only in the prose. Convention: a trailing superscript `ᵉ`
plus one line in the table note.

> Under the current seed floor of 3, **every run2 result is exploratory** (single seed). Any table
> citing them carries the mark until they reach ≥3 seeds.

## Figures

Keep the role split the draft already uses:

| Figure | Role |
|---|---|
| Fig 1 | Overview schematic (D/C arms, calibration, honeytokens) |
| Fig 2 | ROC-space scatter with (ε,0)-DP frontier curves |
| Fig 3 | Capacity-axis bar chart (8 probes × 2 arms) |
| Fig 4 | Proposition 1's bound plus measured points |

**Every table is generated by `make_tables.py` alone.** No hand-transcribed numbers — the draft's
Newcombe intervals were computed by hand, which is exactly where two of the inconsistencies came
from.

## Cost reporting

Every study reports **accelerator-hours** and **run count**, plus the GPU-model composition (Colab
assigns different accelerators per session; without the model, hours are not comparable).

## 实验怎样比较 D 与 C？

**先用含 D 的语料微调，再冻结同一个模型，分别尝试生成 D 和 C。**

![D/C实验流程示意；不是实验数据图](../../../../artifacts/capacity_axis_20260902/figures/briefing/workflow.png)

**D：微调中出现过的目标；C：从本次微调语料中排除的目标。**例如 D 是 alice17@example.org，C 是 bruce24@example.org：都是邮箱，具体字符串不同；前者进入微调语料，后者没有。此例仅为说明，非实验原始记录。

**攻击时改变什么？**本次GCG攻击利用梯度搜索提示中可修改的token（文本片段），优化器知道要生成的目标。k是可修改位置的数量；模型权重保持冻结。命中C表示未参与本次微调的目标也可能被强制生成。

本次主扫描：一个 GPT-2 124M 微调模型；每组25人，每人SSN（社会安全号码格式）和email两个合成字段，共50靶标/组。三个seed是三次不同随机初始化的攻击，不是三次独立训练。C的“未训练”只指本次微调。


## 完整 D/C 抽取率：总体与两个字段

**随着 k 增大，两组抽取率都升高；判断成员差异还要比较 D 与 C 的距离。**

![全14个k的D/C抽取率与95%点区间；字段拆分为探索性](../../../../artifacts/capacity_axis_20260902/figures/briefing/rates_full.png)

**读图：**蓝色是D，橙色是C。α（forcing floor）就是C的抽取率；τ是D抽取率减C抽取率，单位为“百分点”。例如82.00%−80.67%=+1.33个百分点。

每个总体点为150次攻击/组（25人×2字段×3seed）；每个字段点为75次攻击/组。误差线是95%点区间，表示估计的不确定性，不是95%的攻击结果落在其中；各点区间不构成整条曲线的同时保证。

成功沿用实验的exact_match规则：规范化后，完整目标值出现在生成文本中；不要求整段输出只含目标。k=0是单独的固定提示基线，提示/优化目标形式与GCG不同。横轴等距排列，不代表k的数值差。

![D/C × SSN/email × 全14个k的成功攻击次数；探索性描述](../../../../artifacts/capacity_axis_20260902/figures/briefing/counts_full.png)

## D/C匹配平衡诊断

**不属于 H1-H5 的统计检验；它检查两组在训练经历之外是否足够相似。**

**E17做什么？**从未训练目标池中，为D选择同一字段、长度和参考难度尽量接近的C。匹配不要求字符串相同；匹配记录也不保证最终入选的两组已经平衡。这里检查的是实际攻击目标。

![实际攻击目标的六项SMD及95%bootstrap区间；阴影为±0.1诊断带](../../../../artifacts/capacity_axis_20260902/figures/briefing/balance.png)

| ssn | 字符数 | 0.000 | [0.000, 0.000] | 是 |
| ssn | token数 | -0.074 | [-0.667, 0.465] | 是 |
| ssn | H 信息量 | 0.082 | [-0.493, 0.643] | 是 |

**变量如何理解？**字符数是字符串有多少个字符；token数是分词器把它切成多少块；H是参考模型认为这个字符串有多“意外”的信息量（bits），越大表示参考模型赋予它的概率越低，不是直接测得的攻击难度。

**诊断结果：**SMD=(D均值−C均值)/合并标准差，越接近0越相似。SSN三项点估计均满足预定 |SMD|<0.1；email三项均未满足，且D邮箱平均更长、token更多、H更大。0.1是平衡诊断线，不是p值。

每字段25人/组。email不平衡限制H2/H3/H5的成员性解释；当前表不能算出它造成多少抽取率差异。H4只使用C，不依赖D/C匹配差值。


## H1：提示容量增加，C是否更容易被生成？

**当前数据支持总体上升趋势；局部点仍可能回落。**

![H1：控制组正容量曲线及三个攻击seed的变化；主线带95%点区间](../../../../artifacts/capacity_axis_20260902/figures/briefing/h1_floor.png)

**实验前假设**
零假设：C抽取率α与k无关，总体曲线为平。实验前预期：α随k单调不降。这里考察C，不是D−C。

**怎样判断**
用Spearman相关系数ρ衡量排序趋势，接近+1表示强上升。按人员重新抽样并重复计算，所得95%区间完全大于0才通过。这个判据不能证明逐点单调。

**结果**
ρ=0.9890
95%区间 [0.9779, 0.9945]
每组25人中的C组、50目标、3个攻击seed。

**是否符合预期？**符合总体上升判据。例如C在k=20为80.67%，到k=64为96.67%；但k=32到48由92.00%降至91.33%。因此不能说每增加一个k都更高，更不能把总体趋势当成每个靶标必然单调。

**对论文的意义与下一步：**未参与微调的目标也会随攻击容量增加而更常被命中，因此“抽取成功”本身不足以归因于训练记忆。跨模型、其他攻击器能否复现这一趋势，需要另做实验。

原始p=0.000100；Holm调整p=0.000400。p衡量在零假设与计算模型成立时，出现当前或更极端统计结果的程度；它不是假设为真的概率。Holm用于控制H1-H4一起检验时的误报，四项并不因此成为同一个假设。


## H2：有没有一个 k，让 C 成功率足够低？

**原始1%要求尚未分辨：观察到0次成功，也不能确认总体成功率不超过1%。**

![低容量C成功率和95%区间；1%、5%、9%是允许上限，不是不同实验](../../../../artifacts/capacity_axis_20260902/figures/briefing/h2_floor.png)

**实验前假设**
存在某个k≥1，使控制组真实成功率α不超过1%。推广写法是α≤ε；ε表示允许的C成功率上限，例如1%、5%或9%。

**预定判据**
要求α的95%区间上界≤ε，不能只看观察成功率。在“命中即判断为训练成员”的规则下，C被误判的概率就是α。

**结果与判定**
k=1、2、3均为0/150次命中；但保守区间上界仍为10.33%，高于1%。因此未确认1%条件，也未证明它不可能成立。

**为什么图上k=4的上界反而较低？**它观察到2/150次成功（1.33%），主分析用人员bootstrap得到上界3.33%；零命中的k=1-3则换用保守Wilson区间，上界10.33%。这是区间方法切换的结果，不能解释成k=4比零命中的点更安全。

**对结果的影响：**k=4是否满足5%上限依赖区间方法。若也按同一Wilson约定计算，其上界为12.60%。所以“5%时有k=4”只能作为当前表的条件性候选，不能当作已验证的可靠操作点。

设计预估约9%的分辨范围；按实际采用的保守区间，零命中上界为10.33%，两者不是同一个数。下一步需要预先统一区间方法和所需精度，再增加独立控制人员。

**为什么加第二个条件？**
如果D和C都很少成功，虽然C低，攻击也不一定能区分训练成员。成员识别还需要D的成功率明显高于C。

**“明显高于”怎么读？**
对差值τ=D−C计算95%区间；整个区间在0右边（下界>0）才支持D更高。区间跨0则方向未分辨。

**与设计原文的关系**
原文只要求“差值区间不含0”，没有限定正向。按字面，在ε=100%时k=64也入选，但其D−C为−6.00个百分点，方向相反。表中第三列明确展示成员识别所需的正向条件。

表中k是当前混合区间规则下的描述性映射；5%、9%、10%行出现k=4的原因见上一页。100%上限几乎放弃控制误报，k=64的负差值也不能作为正向成员信号。

最终判定：1%条件未分辨；没有得到支持的正向联合操作点。设计未规定跨所有k如何做一个整体检验（“全局检验”），故不能宣称已正式证明“任何k都不存在”。H2没有有效p值，旧表中1只是占位。

## H4：先把“成正比”说清楚

**假设是：目标信息量 H 翻倍，所需首次命中容量 k_min 也约翻倍。**

**实验前假设：k_min(t) ≈ H(t) / β。**H4只使用控制组C，希望用一个固定的β，把目标信息量转换成需要的提示容量。

| 符号 | 含义 |
| --- | --- |
| t | 某一个具体目标字符串。 |
| H(t) | 参考模型给目标t的自信息量，单位bits；目标越不被参考模型预期，H通常越大。 |
| k_min(t) | 在本次正容量扫描中，三个固定攻击seed任一次首次成功时，最小的已观察k。 |
| β（beta） | 比例模型中的换算常数，单位bits/token：每个自由提示token对应多少目标信息量。 |

**示意例子（不是实测数据）：**若β=10 bits/token，H=40 bits对应k_min≈4；H=80 bits对应k_min≈8。两者同时翻倍，这就是成正比。

**为什么拟合里会出现斜率γ？**把比例公式两边取对数：
log(k_min) ≈ log(H) − log(β)
再允许数据自由决定斜率：log(k_min) = a + γ × log(H) + error。

**新增符号的含义**
log：对数变换。
a：直线截距。
γ（gamma）：对数坐标上的斜率。
error：H未解释的差异与攻击随机性。

比例关系要求γ=1，且此时a=−log(β)。如果γ不等于1，就不能再从截距a报告一个通用的bits/token换算常数。H是参考模型的描述量，不是经验证的确定性容量下界。


## H4：数据是否支持这条比例关系？

**γ的95%区间排除1；在当前工作模型下，简单比例关系不适合这些控制目标。**

![H4斜率γ及95%人员bootstrap区间；比例模型要求γ=1](../../../../artifacts/capacity_axis_20260902/figures/briefing/h4_gamma.png)

**斜率怎样算出来？**
对50个C目标，先记录每个目标的首次成功网格。例如在k=4失败、k=6首次成功，阈值工作模型将其记为(4,6]的区间信息。

用Weibull统计模型，寻找让这些区间观察最可能出现的参数（最大似然估计），得到γ。再按25名人员重抽样并重复拟合10,000次，得到95%区间。

**预定判据**
γ的95%区间排除1，反驳简单比例形式。这里检验γ是否为1，不是检验它是否为0。

**结果：**γ=3.484486，95%区间[2.811469, 4.209360]；原始p=0.000100，Holm p=0.000400。区间整体高于1，未满足成正比的要求。

**这一判定有何限制？**控制组7/50个靶标在首次成功后，于某个更大的k又全部失败。也就是说，“失败→成功→失败”真实存在；首次命中不是确定的能力门槛，(4,6]只是阈值模型的解释。本次没有到64仍未命中的控制目标。

**对论文与下一步：**不能据此给出一个可迁移的通用β。需要进一步检查字段差异、攻击随机性和非线性关系；这些是新研究方向，不能把γ≈3.48当成已经建立的新普遍定律。

“工作模型”是这次估计使用的统计近似，并非物理定律。本页沿用当前主分析的“三个seed首次任一命中”口径；Weibull工作分布及p算法为重分析中披露的实现约定，不能追溯称为事前固定。


## H5：D−C 的差值会在中间容量达到峰值吗？

**k=4和12是当前并列最高点，但尚未定位一个稳定、可靠的最优容量。**

![H5探索性：D−C差值曲线及95%点区间，峰位置包络另行标示](../../../../artifacts/capacity_axis_20260902/figures/briefing/h5_peak.png)

**实验前假设**
预期差值τ随k先升后降，在1与64之间出现内部峰；对照是单调或平坦关系。H5研究D−C的峰，不是D或C自身成功率的峰。

**为什么叫探索性？**
实验前就判断当前人数不足以可靠识别峰形，因此H5只用于提出后续问题，不作为确认性发现，也不参加H1-H4的Holm校正。

**预定判断思路**
重复抽样看最高点落在哪里，其95%位置包络应避开两端；同时用弯曲方向检查是否确有“先升后降”。重分析保留所有并列最高点。

**观察结果：**k=4、12并列+2.67个百分点，但各自差值区间均跨0。峰位置的95%包络为[4,48]，范围很宽；它表示最高点位置的不确定性，不表示此区间内所有k都好。

**是否符合假设？**位置条件在字面上通过。b是拟合曲线的弯曲系数，负值表示向下弯；本次b=-0.00391，95%区间[-0.01660, 0.00956]含0，未支持明确的峰形。探索性单侧p=0.2810，整体仍不确定。

下一步：先规定峰值至少应高出两侧多少，再增加独立人员并加密候选容量。当前不能宣称k=4或12最优，也不能因证据不足就宣称曲线平坦。b仅是对log(k)拟合二次曲线的弯曲系数。

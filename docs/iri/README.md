# IEEE IRI 2026 — a separate paper

**This is not the forcing paper.** Do not merge its claims with
*Forcing, Not Remembering: Calibrating Optimization-Based Memorization Audits of Language Models*
(IEEE SaTML 2027), whose materials live in the repo root and `.ai/research/`.

| File | Role |
|---|---|
| `IRI_outline.md` | Section outline, 6 pages, IEEE two-column |
| `IRI_paper.tex` | The draft |

Framing: "the afterlife of personal data in language models" — quantifying PII extractability across
training frequency and content structure. It reuses this repo's corpus generator and attack code but
makes different claims from different evidence.

`IRI_paper.tex` is also the repo's only IEEE-format LaTeX template, so it is worth keeping to hand
when converting the SaTML draft from USENIX format.
